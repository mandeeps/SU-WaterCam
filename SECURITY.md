# Security Policy

## Supported versions

Only the current node release, signed tag `v2026.11.0` (2026-11-15), and `main` after it
are maintained. Older releases aren't patched: update the unit to the current tag
(`docs/RELEASES.md`, "Updating a node").

## Reporting a vulnerability

Open a private security advisory on this repository (Security → Advisories → Report a
vulnerability), or contact the UFONet team maintainers directly. Don't describe it in a
public issue.

How the units are protected (network access, signed releases, the checked capture program)
is in [docs/NODE_SECURITY.md](docs/NODE_SECURITY.md).
